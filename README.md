# Home Assistant add-on repository: Rack Display

[![Add repository](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fjorissynaeve%2Fhomeassistant_rackdisplay)

Add-on **Rack Display**: SSD1306 OLED info screen + button (reboot / shutdown) for a Raspberry Pi, ported from
the old `infoscreen.py`. See [rackdisplay/DOCS.md](rackdisplay/DOCS.md).

Install: Settings -> Add-ons -> Add-on store -> ⋮ -> Repositories -> add
`https://github.com/jorissynaeve/homeassistant_rackdisplay`.
